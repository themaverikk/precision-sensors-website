Precision Sensors static website

Files
- index.html: homepage
- products.html: product range with native in-page chips and native Technical specifications disclosures
- style.css: page styles
- assets/: only images used by the pages

Deployment
Upload the contents of this folder to the root of the GitHub Pages publishing branch/folder. Keep the assets/ folder alongside the HTML files.

Navigation and product chips use ordinary HTML links. Technical specifications use native <details>/<summary>, so these controls do not depend on JavaScript. Contact uses the phone dialer and email client via tel:/mailto: links.
